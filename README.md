# 자료등록 작업실

엑셀·사진 PDF로 등록명세서를 만들고 월별 등록현황을 정리합니다.

- **등록명세서**: 엑셀 항목과 PDF 사진을 불러와 인쇄
- **월별 현황**: 건수·수량 집계와 구분별 엑셀 저장
- **PDF 분리**: 표지·목록을 제외하고 한구·한기로 분리

## 실행

먼저 `museum-registration-source.zip`을 내려받아 빈 폴더에 압축을 풀고, 그 폴더에서 아래 명령을 실행하세요.


```sh
python -m http.server 8000 --directory dist
```

브라우저에서 http://localhost:8000 을 엽니다. 별도 가입이나 API 키가 필요 없습니다.

## 사용

등록목록을 올리고 열 연결과 소장구분을 확인한 뒤 결과를 저장하세요. `sample.csv`는 가상의 집계 예제입니다. 명세서 사진 PDF는 기존 고정양식을 기준으로 하므로 다른 양식은 사진 매칭을 확인해야 합니다.

파일은 브라우저에서 처리합니다. 실제 등록자료·사진·과거 작업파일은 포함하지 않았습니다. 한기·한구·한이 구분과 보고 양식은 기관별 수정이 필요합니다.

복잡한 수식·개체가 있는 엑셀은 지원이 제한됩니다. 분리 파일은 개인정보 삭제 도구가 아니며 숨은 데이터가 남을 수 있습니다. 원본과 결과를 확인해 사용하세요.
