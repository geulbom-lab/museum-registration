# 소장품 등록명세서 자동생성기

**[▶ 등록명세서 만들기 · 바로 사용하기](https://geulbom-lab.github.io/museum-registration/registration.html)**

엑셀과 사진 PDF를 불러와 **소장품 등록명세서**를 만듭니다. 설치·회원가입·API 키 없이 위 링크에서 바로 시작하세요.

> 이 GitHub 화면은 설명과 파일을 보는 곳입니다. 실제 도구는 위의 **바로 사용하기**를 누르면 열립니다.

## 준비할 것

- 소장품 정보가 담긴 **엑셀 파일**
- 소장품 사진이 담긴 **PDF 파일**

## 세 단계로 사용하세요

| 순서 | 할 일 |
| --- | --- |
| ① 파일 불러오기 | 엑셀과 사진 PDF를 선택합니다. |
| ② 연결 확인하기 | 엑셀 항목과 소장품 사진이 맞게 연결됐는지 확인합니다. |
| ③ 명세서 저장하기 | 출력 결과를 확인하고 인쇄하거나 PDF로 저장합니다. |

파일은 브라우저 안에서 처리합니다. 사진 PDF 양식이 다르면 사진 연결을 확인하고, 최종 출력 결과를 원본과 대조하세요.

## 컴퓨터에 파일로 보관하려면

웹사이트에서 바로 사용하는 대신 파일을 내려받아 사용할 수도 있습니다.

1. [registration.html 다운로드](https://github.com/geulbom-lab/museum-registration/raw/refs/heads/main/registration.html)를 저장합니다.
2. 저장한 파일을 더블클릭해 브라우저에서 엽니다.
3. 위의 세 단계대로 파일을 불러와 명세서를 만듭니다.

## 공개 파일

- `registration.html`: 등록명세서 생성 도구. 소스와 필요한 라이브러리가 포함된 단일 HTML입니다.

현재 공개본은 **등록명세서 자동생성 기능만** 제공합니다. 실제 소장품 자료·사진·작업기록은 포함하지 않습니다.
