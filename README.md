# 소장품 등록명세서 자동생성기

엑셀과 사진 PDF를 불러와 소장품 등록명세서를 만듭니다.

## 사용 방법

1. [registration.html 다운로드](https://github.com/geulbom-lab/museum-registration/raw/refs/heads/main/registration.html)를 저장합니다.
2. 내려받은 파일을 브라우저에서 엽니다.
3. 엑셀과 사진 PDF를 불러온 뒤 항목과 사진 연결을 확인합니다.
4. 등록명세서를 인쇄하거나 PDF로 저장합니다.

설치·회원가입·API 키 없이 사용합니다. 파일은 브라우저 안에서 처리합니다.
사진 PDF 양식이 다르면 사진 연결을 확인하고, 출력 결과를 원본과 대조하세요.
